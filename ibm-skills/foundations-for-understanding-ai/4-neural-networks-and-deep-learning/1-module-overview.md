# Module Overview

## About this module

When you unlock your phone using facial recognition, use a voice assistant for help, or receive restaurant suggestions after eating out, you’re experiencing deep learning in action. These systems recognize patterns, learn from feedback, and improve without explicit programming for tasks such as these. Deep learning mimics how the human brain processes information. Deep learning uses layers of artificial neurons to identify patterns in data, ranging from social media posts to medical images, navigation directions, and entertainment recommendations.

Welcome to the Neural Networks and Deep Learning module! In this module, you’ll explore how neural networks learn, what makes deep learning effective, how and where deep learning is applied today, and deep learning’s challenges and limitations as it continues to evolve rapidly.

## Learning objectives

After completing this module, you should be able to:

- Identify how a neural network learns from data
- Identify the challenges and limitations of deep learning
- Explain the role of fairness in deep learning use cases
- Determine potential sources of bias in deep learning
