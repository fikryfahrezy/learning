# Module Overview

## About this module

Artificial intelligence is more than a single tool; it’s a whole toolbox that solves different kinds of problems. From guessing the next word you type, to creating an original image from a prompt. AI takes many forms, each with its own advantages.  

Welcome to the AI Forms and Functions module! In this module, you’ll explore predictive AI, decision-making AI, computer vision, and generative AI, and how these different forms of AI are used. You’ll study prompt writing using Google Gemini, discover how machines interpret and create images, and learn how these systems help with daily life tasks. Throughout, you’ll reflect on AI ethics implications.

### Estimated duration

3 hours

## Learning objectives

After completing this module, you should be able to:

- Describe the different forms of AI used for solving problems
- Select the best use case for predictive AI given a scenario
- Differentiate between predictive AI and decision-making AI
- Describe applications for computer vision AI
- Write an AI prompt using Google Gemini to generate a preferred outcome
