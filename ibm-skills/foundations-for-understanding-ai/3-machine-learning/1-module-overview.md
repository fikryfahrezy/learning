# Module Overview

## About this module

Consider the last time a navigation app rerouted you around heavy traffic. How did the app know that vehicles had slowed along your trip? How did it estimate delay times? How did it select the fastest alternate route? The answer to all these questions is machine learning. AI systems in the app gathered and learned from real-time data, adjusting instantly to provide optimal directions to get you on your way.

Welcome to the Machine Learning module! In this module, you’ll learn about the different types of machine learning methods, explore how classical models approach data processing, and understand how these methods impact AI outputs and improve performance in dynamic environments.

## Learning objectives

After completing this module, you should be able to:

- Differentiate between the types of machine learning  
- Use decision trees, linear regression, and logistic regression to offer insights and make recommendations
- Explain how machine learning types impact AI outputs
- Apply strategies for improving AI accuracy
