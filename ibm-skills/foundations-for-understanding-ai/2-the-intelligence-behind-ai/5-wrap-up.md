### Question 1: Disclosing claim approval factors

A claims-processing model must disclose which factors lead to each approval or denial.

Which Pillar of Trust does this scenario represent?

- Privacy
- Fairness
- Explainability
- Robustness

**Answer: Explainability**

Showing the reasoning chain fosters explainability.

### Question 2: Anticipating shopper questions

A retailer's AI identifies likely questions before a shopper even opens a support chat.

Which workplace AI application does this represent?

- Risk management and security
- Workforce and talent management
- Operations and logistics
- Customer experience and engagement

**Answer: Customer experience and engagement**

Anticipating customer needs improves the overall experience and engagement.

### Question 3: Suggesting a breathing exercise

A smartwatch tracks heart rate and suggests a calming breathing exercise when levels rise.

Which application of AI does this represent?

- Health and wellness
- Home and daily life
- Learning and connection

**Answer: Health and wellness**

Monitoring vital signs supports personal health and wellness.

### Question 4: Dimming lights with a smart speaker

A person asks a smart speaker to dim lights and set the thermostat.

Which application of AI does this represent?

- Learning and connection
- Home and daily life
- Health and wellness

**Answer: Home and daily life**

Voice-controlled home automation is a home-and-daily-life use case.

### Question 5: Chatting across languages

A language-exchange app uses instant translation so two students can chat in different languages.

Which application of AI does this represent?

- Home and daily life
- Health and wellness
- Learning and connection

**Answer: Learning and connection**

Real-time translation fosters learning and connection between users.

### Question 6: Checking financial behavior, not just zip code

A bank uses an AI system to perform background checks on loan candidates. The AI system considers not only the candidates' zip codes, but also their financial behavior and payment capacity.

Which Pillar of Trust does this scenario represent?

- Fairness
- Explainability
- Privacy
- Robustness

**Answer: Fairness**

Considering only the zip code where someone lives might lead to unfair bias, which could result in denying a loan to someone who is financially stable.

### Question 7: Brainstorming improvements with AI

Project team members use AI to draft first-round ideas, then they brainstorm improvements with it.

How are humans and computers solving problems together in this scenario?

- Cocreating solutions
- Supporting human tasks
- Assisting decision making
- Guiding and validating outputs

**Answer: Cocreating solutions**

Humans and AI iterate together to shape creative solutions.

### Question 8: Identifying sales trends over time

After collecting sales numbers, an AI tool analyzes the data to identify trends over time.

What step in AI thinking does this represent?

- Pattern analysis
- Decision logic
- Input recognition
- Output generation

**Answer: Pattern analysis**

The system identifies trends inside the data, which is pattern analysis.

### Question 9: Editing an AI-generated news summary

An editor reviews an AI-generated news summary and edits it for tone before publishing.

How are humans and computers solving problems together in this scenario?

- Cocreating solutions
- Assisting decision making
- Supporting human tasks
- Guiding and validating outputs

**Answer: Guiding and validating outputs**

The human checks and refines the AI's output for accuracy.

### Question 10: Recognizing octagon-shaped stop signs

A model notices that stop signs always share an octagon shape and red color.

What stage of computer learning does this represent?

- Pattern discovery
- Feedback implementation
- Data exposure
- Rule adjustment

**Answer: Pattern discovery**

Recognizing recurring features is pattern discovery.

### Question 11: Absorbing thousands of example sentences

An app exposes language learners to thousands of example sentences, helping them absorb vocabulary, grammar, and usage patterns.

What human learning method does this represent?

- Memory
- Trial and error
- Data exposure
- Imitation

**Answer: Data exposure**

The model is first exposed to information it must learn from.

### Question 12: Streaming raw images to a server

A traffic camera streams raw images to an AI server, allowing the system to begin processing them.

What step in AI thinking does this represent?

- Decision logic
- Input recognition
- Output generation
- Pattern analysis

**Answer: Input recognition**

First, the system must get the information before it can do anything else.

### Question 13: Offering forecast insights in seconds

Meteorologists feed weather data into an AI that offers forecast insights in seconds.

Which machine feature makes this possible?

- Real-time adjustment
- Speed of computation
- Handling large datasets
- Scalability across systems

**Answer: Speed of computation**

Rapid calculation enables AI to analyze massive weather models efficiently.

### Question 14: Substituting a missing spice

Which aspect of reasoning does this represent?

- Transparency
- Adaptivity
- Contextuality

**Answer: Adaptivity**

Changing approaches in real time is adaptivity.

### Question 15: Scoring essays within minutes

A teacher uploads students' essays and receives scores plus comment suggestions within minutes.

Which classroom AI application does this represent?

- Automated grading
- Educational chatbot
- Personalized learning

Instant scoring and feedback are hallmarks of automated grading.
