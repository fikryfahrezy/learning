### Question 1: Refining a speech model with limited transcripts

A speech recognition project begins with a limited set of transcribed audio clips, then ingests thousands of hours of raw speech to refine the model's understanding of accents.

Which machine learning model does this represent?

- Reinforcement learning
- Supervised learning
- Unsupervised learning
- Semi-supervised learning
- Self-supervised learning

**Answer: Semi-supervised learning**

A small, labeled portion, along with extensive unlabeled audio, defines semi-supervised learning.

### Question 2: Formatting a claim summary

An insurance chatbot retrieves customer details from a policy database and returns a neatly formatted claim summary with numbered sections and consistent headings.

Which output does this represent?

- Structure
- Creativity
- Improvement

**Answer: Structure**

A clearly labeled summary helps the customer and the insurer review claim information quickly.

### Question 3: Returning false answers after a product update

After a major product update, a customer service AI system returns false answers when asked about new product features.

Which strategy for improving AI accuracy does this represent?

- Human-in-the-loop feedback
- Fine-tuning models
- Post-generation verification
- Data quality improvements

**Answer: Data quality improvements**

The AI system will require improvements in data quality, particularly regarding data on new product features and features that are not yet available.

### Question 4: Flagging unusual bank transactions

A bank's fraud detector flags transactions that look unusual compared with most of the everyday activities, even though none of the data was labeled as fraud.

Which machine learning model does this represent?

- Semi-supervised learning
- Self-supervised learning
- Unsupervised learning
- Reinforcement learning
- Supervised learning

**Answer: Unsupervised learning**

Spotting anomalies in unlabeled data is an unsupervised learning task.

### Question 5: Fact-checking an AI-generated article

A journalist uses trusted scientific sources to fact-check an AI-generated article before publishing it.

Which strategy for improving AI accuracy does this represent?

- Human-in-the-loop feedback
- Fine-tuning models
- Data quality improvements
- Post-generation verification

**Answer: Post-generation verification**

Post-generation verification involves reviewing AI outputs after they're created to identify and correct errors and hallucinations.

### Question 6: Reconstructing cropped photo patches

An image model crops out random patches of a photo and learns to reconstruct the missing regions without any human-supplied labels.

Which machine learning model does this represent?

- Semi-supervised learning
- Supervised learning
- Reinforcement learning
- Self-supervised learning
- Unsupervised learning

**Answer: Self-supervised learning**

The model sets up a self-created puzzle, a characteristic of self-supervised learning.

### Question 7: Rewriting blog content in real time

An editor reviews AI-generated blog content in real time, rewriting parts as needed to keep it accurate and on topic.

Which strategy for improving AI accuracy does this represent?

- Fine-tuning models
- Data quality improvements
- Human-in-the-loop feedback
- Post-generation verification

**Answer: Human-in-the-loop feedback**

Human-in-the-loop feedback involves real-time corrections during the creation process, improving the final output.

### Question 8: Estimating next month's revenue

A finance team wants to estimate next month's revenue using current ad spend, store hours, and seasonal pricing data. They expect the output to be a specific dollar amount.

Which classical machine learning model should the team use?

- Linear regression
- Decision tree
- Logistic regression

**Answer: Linear regression**

Linear regression recommends continuous values using more than one input.

### Question 9: Explaining a specialist referral decision

A healthcare provider uses a model that asks yes-or-no questions to determine whether a patient should be referred to a specialist. The provider wants to understand how the model reaches each decision.

Which classical machine learning model should the provider use?

- Logistic regression
- Decision tree
- Linear regression

**Answer: Decision tree**

Decision trees are transparent and easy to explain, making them useful in healthcare settings.

### Question 10: Learning a video game through scores

An AI system learns to play a video game by trying different moves, receiving scores, and adjusting its strategy based on results.

Which machine learning model does this represent?

- Reinforcement learning
- Semi-supervised learning
- Supervised learning
- Unsupervised learning
- Self-supervised learning

**Answer: Reinforcement learning**

Reinforcement learning is based on agents taking actions, receiving feedback in the form of rewards or penalties, and improving performance over time through trial and error.

### Question 11: Retraining a vision model on a new bolt

An automotive company retrains its vision model on thousands of images of a newly designed bolt, enabling the robot arm to identify and install it correctly on the assembly line.

Which strategy for improving AI accuracy does this represent?

- Data quality improvements
- Fine-tuning models
- Human-in-the-loop feedback
- Post-generation verification

**Answer: Fine-tuning models**

Updating the model with targeted examples of the new bolt is a fine-tuning effort.

### Question 12: Combining memes with brand colors

A marketing assistant AI combines trending memes with brand colors to invent fresh social media graphics that capture attention.

Which output does this represent?

- Structure
- Creativity
- Improvement

**Answer: Creativity**

Generating unique, eye-catching content is the key value in this example.

### Question 13: Covering more shelves with fewer steps

A warehouse robot tracks its daily travel distance and adjusts its routes to cover more shelves with fewer steps each week.

Which output does this represent?

- Creativity
- Structure
- Improvement

**Answer: Improvement**

The robot's value lies in its ability to improve over time through feedback and learning.

### Question 14: Recommending a price for a new listing

A real estate model is provided with house features and their known sale prices, and then learns to make pricing recommendations for a new listing.

Which machine learning model does this represent?

- Reinforcement learning
- Semi-supervised learning
- Self-supervised learning
- Unsupervised learning
- Supervised learning

**Answer: Supervised learning**

Using labeled examples of houses with prices to recommend a value is an example of supervised learning.

### Question 15: Predicting pass or fail on a math exam

A school administrator uses a model to suggest whether students will pass or fail a math exam based on their attendance and homework scores.

Which classical machine learning model should the administrator use?

- Linear regression
- Logistic regression
- Decision tree

**Answer: Logistic regression**

Logistic regression is used to classify data into two categories, such as pass or fail.
